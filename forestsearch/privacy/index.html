휴양림 빈자리 개인정보처리방침

시행일: 2026년 10월 17일 · 개발자: Woongs Lab · 패키지: com.woongslab.forestsearch

Woongs Lab(이하 "개발자")은 "휴양림 빈자리" 앱(이하 "앱")을 이용하는 분의 개인정보를 소중히 다루며, 아래와 같이 처리합니다. 앱은 개발자 서버를 두지 않으며, 개발자는 이용자의 개인정보를 수집하거나 서버로 전송하지 않습니다.

1. 앱이 하는 일

앱은 국립자연휴양림 예약 사이트 "숲나들e"(www.foresttrip.go.kr)의 예약현황을 이용자의 기기에서 직접 읽어, 토요일·공휴일에 빈 숙소와 야영장을 찾아 보여 줍니다. 앱은 숲나들e와 관련 없는 비공식 앱이며, 예약은 숲나들e에서 이루어집니다.

2. 처리하는 정보와 목적

정보목적저장 위치
검색 설정(지역·휴양림·월·시설·즐겨찾기·숨김 등)검색 조건 유지기기 내부 저장소
마지막 검색 결과결과 화면·홈 화면 위젯·새 빈자리 비교기기 내부 저장소
숲나들e 로그인 세션 정보(쿠키)이용자가 숲나들e에 로그인한 상태에서 예약현황 조회기기 내부 저장소
광고 식별자·기기 정보 등(광고 SDK가 수집)광고 표시Google이 처리 (3항 참고)

앱은 이름·연락처·위치 정보·사진·연락처 목록을 수집하지 않습니다.

3. 숲나들e 로그인

  • 로그인은 앱 안에 열리는 숲나들e 화면(WebView)에서 이루어지며, 아이디와 비밀번호는 숲나들e 사이트로 직접 전송됩니다. 앱과 개발자는 아이디와 비밀번호를 읽거나 저장하거나 전송하지 않습니다.
  • 로그인 후의 세션 쿠키만 기기에 보관해 조회에 사용합니다. 앱에서 로그아웃하거나 앱 데이터를 지우면 삭제됩니다.
  • 숲나들e 사이트의 개인정보 처리는 해당 사이트의 방침을 따릅니다.

4. 광고(Google AdMob)

앱은 Google AdMob으로 배너·전면 광고를 표시합니다. 이 과정에서 Google이 광고 ID, IP 주소, 기기·앱 정보 등을 수집·이용할 수 있으며, 개인 맞춤 광고는 기기의 광고 설정에서 끄거나 광고 ID를 재설정할 수 있습니다. 자세한 내용은 Google의 광고 데이터 이용 안내와 Google 개인정보처리방침을 참고하세요.

5. 외부로 보내는 요청

  • 숲나들e(www.foresttrip.go.kr): 예약현황 조회
  • GitHub(raw.githubusercontent.com): 휴양림 목록과 요금 참고 파일을 하루 한 번 내려받음 (이용자 정보를 보내지 않음)
  • Google 광고 서버: 광고 표시

6. 알림·권한

  • 알림: 새 빈자리와 검색 진행 상황을 알립니다.
  • 인터넷·네트워크 상태: 조회와 광고에 필요합니다.
  • 포그라운드 서비스(데이터 동기화): 몇 분씩 걸리는 검색을 진행 알림과 함께 실행합니다.
  • 배터리 최적화 제외 요청: 자동 검색이 제때 실행되도록 이용자가 허용한 경우에만 적용됩니다.

7. 보관과 삭제

모든 설정과 결과는 이용자의 기기에만 있으며, 앱을 삭제하거나 기기 설정의 "앱 정보 → 저장 공간 → 데이터 삭제"를 하면 모두 지워집니다. 개발자는 보관하는 이용자 정보가 없어 별도 삭제 요청 대상이 없습니다.

8. 아동

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 알면서 수집하지 않습니다.
